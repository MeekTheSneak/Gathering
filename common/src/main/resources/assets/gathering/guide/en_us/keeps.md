# Playing for keeps

Some servers let a table play for keeps. Nobody is staked without being asked.

1. Before the game starts, everybody at the table is asked, and shown how many cards each player stakes.
2. The game plays for keeps only if everyone agrees. If anybody declines, it is played with nothing at stake. On a server that insists on keeps, the game does not start.
3. The staked cards are taken at random after the shuffle and lie face up beside the table all game.
4. The winner keeps them.

A table played for keeps says so in amber beside the turn for as long as the game lasts. Practice tables never play for keeps.
