# Audit, September 2026

What a coverage pass over the scripted scene and an adversarial read of every subsystem found, and what became of each finding.
Every finding was verified by hand against the code and, where fixed, pinned by a test that fails without the fix.

Readers that ran: game core, visibility and persistence, table screen input and render, block view, deck and collection screens, client infrastructure, server table, server economy, items and network; coverage of zone moves, library verbs, card state, counters and writing, table and social, decks and collection.
Readers that did not run (subagent budget): pack, draft and trade screens; sealed and booster; card data and decks; draft, ante, trade and match config; coverage of keys and commands; coverage of draft, trade, ante, loaners and replay.
